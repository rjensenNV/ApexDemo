# ApexDemo Maintainers

This file identifies maintainers for the `rjensenNV/ApexDemo` repository. It does not identify or replace maintainers of the upstream `NVIDIA/apex` repository.

| Maintainer | GitHub | Areas of responsibility | Role |
| --- | --- | --- | --- |
| `rjensenNV` | [@rjensenNV](https://github.com/rjensenNV) | Repository-wide ownership, policy, issue triage, and pull-request review | Maintainer |

## Responsibilities

The maintainer sets repository direction, reviews and merges contributions, keeps public documentation and settings consistent, and redirects private security reports to NVIDIA PSIRT. These activities are performed on a best-effort basis unless a separate NVIDIA support agreement applies.

## Contact and escalation

- Project questions and maintainer escalation: use [GitHub Issues](https://github.com/rjensenNV/ApexDemo/issues) or the relevant pull request.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md); never disclose them through a public issue.

## Maintainer role changes

Propose a maintainer change through a public issue and a pull request updating this file and [GOVERNANCE.md](GOVERNANCE.md). The current repository owner approves role changes. Security-sensitive or personnel-sensitive details should not be published in the issue or pull request.
